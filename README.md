# Microcontrolador ATmega328P

Repositório destinado à disciplina de Microcontroladores I.

## Projeto Final — Termo-Higrômetro Digital

### 1. Objetivo

Desenvolver um protótipo de termo-higrômetro digital utilizando o 
microcontrolador ATmega328P, capaz de medir, exibir e armazenar 
dados de temperatura e umidade relativa do ar.

O dispositivo contará com uma interface gráfica configurável, 
operada por um encoder rotativo, e permitirá o registro das 
medições em um cartão SD, associadas à data e hora fornecidas 
por um módulo RTC.

### 2. Escopo do Produto

O Produto Mínimo Viável (MVP) contempla as funcionalidades 
essenciais para aquisição, exibição e armazenamento dos dados 
ambientais.

- **Funcionalidades inclusas (MVP):**
    - Aquisição de temperatura e umidade por meio de sensor digital.
    - Exibição simultânea das grandezas medidas e seus respectivos ícones.
    - Armazenamento das medições e configurações em cartão SD.
    - Registro de data e hora por meio de um módulo RTC.
    - Interface gráfica para configuração do relógio e da unidade de medida.
    - Navegação e interação por meio de um encoder rotativo.

- **Funcionalidades fora do escopo:**
    - Modo de baixo consumo de energia do display.
    - Desenvolvimento de PCB personalizada.
    - Comunicação sem fio via Bluetooth ou Wi-Fi.
    - Desenvolvimento de gabinete personalizado.
