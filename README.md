# Microcontrolador ATMega328p
Repositório para disciplina de Microcontroladores I.
## Objetivos
- Compreender microcontroladores de 8 bits.
- Conhecer os conceitos de sistemas microcontrolados aplicando-os no desenvolvimento de sistemas eletrônicos.
- Compreender e utilizar o hardware interno dos microcontroladores.
- Estruturar soluções adequadamente na forma de algoritmos e fluxogramas relacionando-os à programação de microcontroladores.
- Utilizar, projetar e programar sistemas eletrônicos com microcontroladores de 8 bits.
- Programação Assembly para microcontroladores.
- Programação C/C++ para microcontroladores.
